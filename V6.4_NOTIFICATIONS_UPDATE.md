# CampusConnect v6.4 - Notifications & UX Polish

## Overview

v6.4 introduces an in-app notifications system and reusable UX components for consistent loading states, empty states, and error handling throughout the application.

---

## Features Added

### 1. In-App Notifications System

**New Files:**
- [lib/models/app_notification.dart](lib/models/app_notification.dart) - Notification data model
- [lib/services/firestore/notifications_service.dart](lib/services/firestore/notifications_service.dart) - Firestore operations
- [lib/providers/notifications_provider.dart](lib/providers/notifications_provider.dart) - State management
- [lib/views/notifications_view.dart](lib/views/notifications_view.dart) - Notifications list UI

**Notification Types:**
- `placementApplied` - When user successfully applies for a placement
- `statusChange` - When application status changes (pending → interview → selected/rejected)
- `announcement` - Admin broadcast messages
- `reminder` - Deadline reminders (future)
- `system` - System notifications

**Firestore Structure:**
```
users/{uid}/notifications/{notificationId}
├── type: string (enum)
├── title: string
├── body: string
├── data: Map (placementId, company, status, etc.)
├── isRead: boolean
├── createdAt: Timestamp
└── expiresAt: Timestamp (optional, auto-cleanup)

announcements/{announcementId}  (Admin-only write)
├── title: string
├── body: string
├── isActive: boolean
├── createdAt: Timestamp
└── expiresAt: Timestamp (optional)
```

### 2. Notification Badge

**New Widget:**
- [lib/views/widgets/notification_badge.dart](lib/views/widgets/notification_badge.dart)

**Features:**
- Real-time unread count badge
- Animated pulse on new notifications
- Badge disappears when all read

### 3. UX Polish Widgets

**Loading States:**
- [lib/views/widgets/loading_widget.dart](lib/views/widgets/loading_widget.dart)
  - `LoadingWidget` - Full-screen loading with message
  - `InlineLoadingWidget` - Button/small space loading

**Empty States:**
- [lib/views/widgets/empty_state_widget.dart](lib/views/widgets/empty_state_widget.dart)
  - `EmptyStateWidget` - Generic empty state

  - `ComingSoonWidget` - Feature placeholder

## Integration Points

### Provider Registration (main.dart)
```dart
ChangeNotifierProvider(
  create: (_) =>
      NotificationsProvider(service: NotificationsService.instance()),
),
```

### AuthGuard Integration
```dart
// On login - initialize
notificationsProvider.initWithUser(user.id);

// On logout - reset
notificationsProvider.reset();
```

### Placement Application Integration
When a user successfully applies for a placement, a notification is automatically created:

```dart
// In PlacementsProvider.applyForPlacement()
await _notificationsService.notifyPlacementApplied(
  userId: userId!,
  placementId: placementId,
  company: company ?? 'Unknown',
  role: role ?? 'Position',
);
```

## Security Rules

Notifications follow UID-scoped access pattern:
```javascript
// Already covered by existing subcollection rule:
match /users/{userId} {
  allow read, write: if isOwner(userId);
  match /{subcollection=**} {
    allow read, write: if isOwner(userId);
  }
}

// New announcements collection (v6.4):
match /announcements/{announcementId} {
  allow read: if isAuthenticated();
  allow write: if false; // Admin-only via console/functions
}
```

## Usage Examples

### Creating Notifications Programmatically

```dart
// Placement applied
await notificationsService.notifyPlacementApplied(
  userId: userId,
  placementId: 'abc123',
  company: 'Google',
  role: 'Software Engineer',
);

// Status change
await notificationsService.notifyStatusChange(
  userId: userId,
  placementId: 'abc123',
  company: 'Google',
  role: 'Software Engineer',
  status: 'Interview Scheduled',
);
```

### Using UX Widgets

```dart
// Loading state
if (isLoading) {
  return const LoadingWidget(message: 'Fetching data...');
}

// Empty state
if (items.isEmpty) {
  return EmptyStateWidget(
    icon: Icons.inbox,
    title: 'No items',
    subtitle: 'Add your first item to get started.',
    actionLabel: 'Add Item',
    onAction: () => _addItem(),
  );
}

// Error state
if (error != null) {
  return ErrorStateWidget(
    message: error,
    onRetry: () => _refresh(),
  );
}
```
