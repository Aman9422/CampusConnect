# CampusConnect v6.6 - Optional Personalization

**Status: ✅ COMPLETE** (January 25, 2026)

## Overview

v6.6 introduces user personalization features with a **privacy-first, offline-friendly** design. All preferences are stored locally using SharedPreferences—no Firestore writes for appearance settings.

---

## Design Principles

| Principle | Implementation |
|-----------|----------------|
| **Privacy-First** | No avatar uploads, no Firebase Storage |
| **Offline-Friendly** | SharedPreferences for all display preferences |
| **Minimal Backend** | Zero Firestore writes for theme/density |
| **Graceful Fallbacks** | displayName falls back to fullName |

## What's NOT in v6.6

❌ Avatar image upload  
❌ Firebase Storage integration  
❌ AI features or eligibility changes  
❌ Firestore rules modifications  
❌ Auth flow changes

## Features Added

### 1. Display Preferences (Local-Only)

**Theme Modes:**
- `system` - Follow device setting (default)
- `light` - Always light mode
- `dark` - Always dark mode

**Layout Density:**
- `comfortable` - More spacing (default)
- `compact` - Less spacing, see more content

### 2. Smart Initials Avatar

**New Widget:**
- [lib/views/widgets/initials_avatar.dart](lib/views/widgets/initials_avatar.dart)

**Features:**
- Circular badge with user's initials
- Deterministic gradient background based on UID hash
- 8 predefined gradient colors
- Same user = same color everywhere

**Initials Logic:**
```
"Aman" → "A"
"Aman Yadav" → "AY"
"" → "U" (fallback)
```

**Widget Variants:**
- `InitialsAvatar` - Base widget with customizable size
- `LargeInitialsAvatar` - 80px for profile headers
- `SmallInitialsAvatar` - 32px for lists

### 3. Profile Text Personalization

| Field | Max Length | Fallback |
|-------|------------|----------|
| `displayName` | 30 chars | fullName |
| `bio` | 120 chars | (empty) |

### 4. Settings Screen

**New File:**
- [lib/views/settings_view.dart](lib/views/settings_view.dart)

**Sections:**
- **👤 Account** - Display name, bio (editable), email (read-only)
- **🎨 Appearance** - Theme selector, density selector
- **🔔 Notifications** - Quick access to notifications
- **ℹ️ About** - App version, privacy policy, terms

### 5. Dark Theme Support

**New Theme:**
- Full Material 3 dark theme
- Dark background: `#121212`
- Dark surface: `#1E1E1E`
- Dark card: `#2D2D2D`
- Proper contrast ratios

**Dark Mode Implementation Pattern:**
```dart
// Used consistently across all views
final isDark = Theme.of(context).brightness == Brightness.dark;

// Background colors
color: isDark ? AppTheme.darkSurface : Colors.white

// Text colors
color: isDark ? Colors.white : AppTheme.gray900
color: isDark ? AppTheme.gray400 : AppTheme.gray600

// Icon colors
color: isDark ? AppTheme.gray400 : AppTheme.gray700
```

**Screens with Full Dark Mode Support:**
- ✅ LoginView - Gradient background, text fields, buttons
- ✅ RegisterView - Gradient background, text fields, buttons
- ✅ ProfileSetupView - Step indicators, form fields, cards
- ✅ EditProfileView - Tab bar, form fields, input decoration
- ✅ NotesView (all 5 tabs) - Cards, lists, text, icons
- ✅ SettingsView - All sections and dialogs
- ✅ Home widgets - FeaturedCard, SkillsGrid
- ✅ Placement cards - Company, role, salary, deadline text

## Usage Examples

### Using Preferences

```dart

// Get layout density
```

## Architecture Notes

### Why SharedPreferences?

1. **No Auth Dependency** - Works before/after login
2. **Offline First** - No network required
3. **Privacy** - Theme preference stays on device
4. **Performance** - Instant reads, no Firestore latency

### Why No Avatar Upload?

1. **Complexity** - Firebase Storage setup, rules, quota
2. **Privacy** - Some users don't want photos
3. **Simplicity** - Initials are unique and recognizable
4. **Performance** - No image loading/caching

### Data Flow

```
User Action → Provider → LocalPreferencesService → SharedPreferences
                ↓
            notifyListeners()
                ↓
            UI Rebuilds
```

## Implementation Notes

### Dark Mode Pattern Used Throughout

Every view that needs dark mode support follows this pattern:

```dart
@override
Widget build(BuildContext context) {
  final isDark = Theme.of(context).brightness == Brightness.dark;
  
  return Scaffold(
    backgroundColor: isDark ? AppTheme.darkBackground : AppTheme.gray50,
    body: Container(
      color: isDark ? AppTheme.darkSurface : Colors.white,
      child: Text(
        'Content',
        style: TextStyle(
          color: isDark ? Colors.white : AppTheme.gray900,
        ),
      ),
    ),
  );
}
```

### Layout Provider Integration

LayoutProvider values are used in UI widgets:

```dart
final layout = context.watch<LayoutProvider>();

// Card padding
padding: EdgeInsets.all(layout.cardPadding),  // 16 or 12

// List item margins  
margin: EdgeInsets.only(bottom: layout.itemSpacing),  // 16 or 10

// Conditional sizing
fontSize: layout.isCompact ? 14 : 16,
iconSize: layout.isCompact ? 20 : 24,
```

### Input Decoration Helper (Auth Screens)

```dart
InputDecoration _inputDecoration(String label, IconData icon, bool isDark) {
  return InputDecoration(
    labelText: label,
    labelStyle: TextStyle(
      color: isDark ? AppTheme.gray400 : AppTheme.gray600,
    ),
    prefixIcon: Icon(icon, 
      color: isDark ? AppTheme.gray400 : AppTheme.gray600,
    ),
    filled: true,
    fillColor: isDark ? AppTheme.darkCard : Colors.white,
    border: OutlineInputBorder(
      borderRadius: BorderRadius.circular(12),
      borderSide: BorderSide.none,
    ),
    enabledBorder: OutlineInputBorder(
      borderRadius: BorderRadius.circular(12),
      borderSide: BorderSide(
        color: isDark ? Colors.white24 : AppTheme.gray200,
      ),
    ),
  );
}
```
