## Overview

- Real-time profile data storage and retrieval
- Profile editing capability with form validation
- Auto-creation of empty profiles on first login
- Graceful handling of incomplete/empty profile data

## Bug Fixes During Implementation

### Issue 1: Null Safety Crashes
**Problem:** Profile screen crashed with "Null check operator used on a null value"  
**Cause:** `profile` could be null when navigating to Profile tab  
**Solution:** Added proper ternary checks with null-safe promotion:
```dart
// Before (crashes)
profile?.academic.program.isEmpty ?? true
    ? 'Not set'
    : profile.academic.program  // Error: profile could be null

// After (safe)
(profile?.academic.program.isEmpty ?? true)
    ? 'Not set'
    : profile!.academic.program  // Safe: parentheses ensure promotion
```

### Issue 2: Dropdown Value Mismatch
**Problem:** Year dropdown crashed with "value: 0" not in items [1,2,3,4,5]  
**Cause:** Empty profile has `year = 0` by default  
**Solution:** Default to 1 if year is 0:
```dart
_selectedYear = (profile?.academic.year ?? 0) == 0 ? 1 : profile!.academic.year;
```

### Issue 3: Nullable Email Parameter
**Problem:** `user.email` is `String?` but `initWithUser()` expected `String`  
**Solution:** Added null coalescing fallback:
```dart
profileProvider.initWithUser(user.id, user.email ?? 'noemail@example.com');
```
